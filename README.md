# Caderninho de Contas

App web de treino de matemática para crianças, inspirado no método Kumon. Treina soma, subtração e multiplicação em folhas de 10 contas, medidas por acerto e tempo.

Tudo roda em um único arquivo HTML, sem servidor, sem conta e sem coleta de dados. O progresso fica salvo no próprio aparelho, com backup por código na Área dos pais.

## Como usar

Abra o [index.html](index.html) no navegador (celular, tablet ou desktop). Não há build nem dependências.

Se o GitHub Pages estiver ativado, o app fica disponível na URL do repositório.

## Estrutura

```
index.html     app completo (HTML, CSS e JS)
fonts/         fonte Andika (Regular e Bold)
```

## Observação

A fonte Andika fica em `fonts/` e é carregada localmente (nenhuma chamada externa). Ela é distribuída sob a licença SIL Open Font License; veja https://fonts.google.com/specimen/Andika.
